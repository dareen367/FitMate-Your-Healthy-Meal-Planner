# 🥗 FitMate – Your Healthy Meal Planner

## 📌 Project Overview

FitMate is a web-based healthy meal planning system designed to generate optimized meal plans based on users' health profiles and fitness goals.

The system uses Mixed-Integer Linear Programming (MILP) to generate balanced meal combinations while considering nutritional requirements, dietary restrictions, allergies, and individual health conditions.

## 🎯 Project Objectives

- Generate personalized and nutritionally balanced meal plans.
- Support different fitness goals, including weight loss, weight gain, weight maintenance, and muscle building.
- Consider health conditions such as diabetes and insulin resistance.
- Account for common food allergies and dietary restrictions.
- Provide meal variety while satisfying nutritional constraints.
- Track user progress and adapt meal plans accordingly.
